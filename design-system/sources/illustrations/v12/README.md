# Acteurs du carnet

Original généré avec transparence, direction crayon fin et aquarelle mate anglaise. Les douze objets sont séparés pour une animation articulée : œuf/coquilles/jaune/bol/fouet, vanille, framboise et biscuit cassé. Même composition au repos et pendant le mouvement, horloge existante du carnet. Les cadrages techniques sont versionnés dans manifeste.json.

Reproduire : `tools/ecriture/.venv/bin/python scripts/bake-illustrations-v9.py --source design-system/sources/illustrations/v12 --catalogue catalogue-v12.json`, puis `tools/ecriture/.venv/bin/python scripts/bake-aquarelles.py --only acteurs/bol,acteurs/oeuf,acteurs/coquille-gauche,acteurs/coquille-droite,acteurs/jaune,acteurs/fouet,acteurs/fleur-vanille,acteurs/gousse,acteurs/framboise,acteurs/speculoos,acteurs/speculoos-gauche,acteurs/speculoos-droite,jack-russell-guide`.
